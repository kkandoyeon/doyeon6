# 교육 프로젝트 협업 대시보드

> 팀원 간 일정, 업무 진행 상황, 문서 협업, 역할 분담을 한 곳에서 관리할 수 있는 프로젝트 대시보드입니다.

## 프로젝트 소개

이 프로젝트는 30명 규모의 교육 프로젝트 팀을 위해 제작된 협업용 대시보드입니다. 
팀원별 역할, 일정, 진행률, 공지사항, 문서 링크를 한 화면에서 확인할 수 있도록 구성되어 있어, 프로젝트 운영의 전체 흐름을 빠르게 파악하고 협업 효율을 높이는 데 목적을 두고 있습니다.

특히 구글 문서 기반 작업과 연결하여 문서 작성, 자료 공유, 업무 진행 상태를 함께 관리할 수 있도록 설계했습니다. 프로젝트의 핵심 정보가 분산되지 않고 한 번에 보이기 때문에 팀원 간 소통과 실행 속도를 높이는 데 유리합니다.

## 주요 기능

- 팀원별 역할 및 담당 업무 확인
- 프로젝트 일정 및 마일스톤 관리
- 진행 상태와 작업 현황 시각화
- 공지사항 및 자료 공유 공간 구성
- 구글 문서와 연계 가능한 협업 구조
- 반응형 웹 디자인으로 다양한 화면에서 사용 가능

## 개발 배경

교육 프로젝트는 여러 사람이 동시에 같은 목표를 향해 움직이지만, 일정, 업무 분배, 문서 관리가 각각 흩어져 있는 경우가 많습니다. 이 대시보드는 그런 분산된 정보를 하나의 중심 페이지에서 정리해, 팀 전체가 현재 상태를 쉽게 공유하고 협업할 수 있도록 돕는 것을 목표로 합니다.

## 기술 스택

- HTML
- CSS
- JavaScript
- 반응형 웹 UI
- Google Docs 연동 구조

## 활용 목적

- 프로젝트 진행 상황을 한눈에 파악
- 업무 책임 분담 명확화
- 팀 협업 효율 향상
- 교육 프로젝트 운영의 체계적인 관리

## 프로젝트 상태

현재는 대시보드 UI 구성과 협업 정보 정리 기능 중심으로 구현되어 있으며, 향후 문서 연동, 실시간 데이터 관리, 일정/진행률 자동화 기능을 확장할 수 있습니다.

---

본 프로젝트는 팀 협업을 더 체계적이고 직관적으로 만들기 위해 설계된 대시보드입니다. 문서 중심의 교육 프로젝트 운영을 보다 효율적으로 지원하는 데 초점을 두고 있습니다.
